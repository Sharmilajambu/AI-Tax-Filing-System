# AI Tax Filing Tool

## Overview
AI Tax Filing Tool is a Java-based application that helps users calculate taxes, receive AI-based suggestions, and manage tax records.

## Features
- Tax calculation
- AI-based tax advice
- Future tax prediction
- Chatbot for tax queries
- Document upload
- Auto tax form generation
- Database storage

## Technologies Used
- Java
- MySQL
- VS Code
- Weka (Machine Learning)

## How to Run

1. Clone the repository
2. Open the project in VS Code
3. Setup MySQL database
4. Run Main.java
